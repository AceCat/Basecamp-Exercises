Filter System — Step by Step

1

User Interaction — FilterBar.vue

User selects a value from one of 4 dropdowns: Time Period (month/quarter), Warehouse (SF/London/Tokyo), Category (5 product types), Order Status (4 states). Each dropdown is a v-model bound to a composable ref.

2

Reactive State Update — useFilters.js

Composable refs (selectedLocation, selectedCategory, selectedPeriod, selectedStatus) update reactively. useFilters() is a singleton so all views share the same state.

3

Watch Trigger — View Component

Each view watches its relevant filter refs. When a filter changes, the view calls getCurrentFilters() to get the current filter state object, then calls the appropriate api.js method.

4

URL Construction — api.js

Axios methods build URLSearchParams, skipping any filter set to 'all'. Example: GET /api/inventory?warehouse=Tokyo&category=Sensors

5

Server Filtering — main.py

apply_filters(items, warehouse, category, status) walks the in-memory list. filter_by_month(items, month) handles both single months (2025-01) and quarters (Q1-2025 expands to 3 months). Both functions chain.

6

Response & Render

Pydantic-validated JSON array returned to the frontend. View updates its reactive ref (items.value = response.data). Computed properties apply any additional client-side sort/search.
